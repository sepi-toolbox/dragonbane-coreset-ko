# Core Set 고유 용어 (dragonbane-ko 용어집 보완)

**정본은 번역자의 한국어판 규칙서·어드벤처·솔로 모험·캐릭터 시트(PDF)** 입니다.
기본 게임 용어는 [dragonbane-ko/docs/용어집.md](https://github.com/sepi-toolbox/dragonbane-ko/blob/main/docs/용어집.md)를 따르고,
아래는 Core Set 콘텐츠에서 정한 표기와 PDF 안에서 표기가 갈린 곳의 통일 기준입니다.

근거 우선순위: 캐릭터 시트 > 규칙서 정의 페이지(장비표·주문 목록·몬스터 도감 등) > 규칙서·어드벤처 다수 용례.
게임 수치·주사위는 영문 2쇄 데이터를 따르고, 문장·용어는 PDF를 따릅니다.

## 무기 · 방어구 · 장비 명명 규칙 (사용자 결정)

- **본문 어순**: 크기·무게 수식어는 앞에 — 중량 크로스보우, 경량 워해머, 소형/대형 방패, 대형 텐트, 경량 나무 곤봉.
- **재질·품질·종류 수식어는 괄호**: 밧줄 (삼베, 10미터), 락픽 (고급), 화살통 (쇠촉), 여관 숙박 (독방).
- **외래어 무기는 붙여 쓰기**(PDF에 붙여 쓴 형태가 있는 경우): 숏보우, 롱보우, 숏스피어, 롱스피어, 체인메일. 그 밖은 PDF 표기(배틀액스, 트라이던트, 패링 대거, 스터디드 레더).
- 방어구: 레더, 스터디드 레더, 체인메일, 플레이트. Mastercrafted = **걸작**.
- 무기 특징: 긴, 은닉, 넘어뜨림, 투척 가능, 막기 불가, 화살통 필요, 피해 보너스 없음, 맨손.
- 공급: 일반 / 드묾 / 희귀 / 유일. 가격 표기 「N 금화 / N 은화 / N 동화」.
- 부싯돌과 부싯깃, 오일 램프, 곰 덫, 잡동사니(Tiny Items).

## 주문 · 마법

- 마법 트릭, 파워 레벨, 랭크, 요구 조건 / 선행 조건, 시전 시간, 사거리, 지속시간, 부채꼴, 마도서, 매개체.
- 시전 구성요소: 말 · 몸짓 · 재료 · 매개체.
- 주문명은 PDF 주문 목록 표기(예: PROTECTOR 보호막, LIGHTNING BOLT 번개 줄기, HEAL WOUND 상처 완치, TREAT WOUND 상처 치료, SCRYING 투영).

| 영문 | 한국어 | 영문 | 한국어 |

| Demon | 악마 | Skeleton | 스켈레톤 (두개골·시체 뼈는 해골) |
| Outskirt | 아웃스커트 | Deepfall Breach | 딥폴 브리치 (the rift만 균열) |
| Um-Durman | 움-두르만 | Iron Forest | 철의 숲 |
| Bothild's Lode | 보틸드의 광맥 | Dragon Empire | 드래곤 제국 |
| Sathmog | 사스모그 | Dranath | 드라나스 |
| Kato the Curious | 호기심쟁이 카토 | Crypt | 묘실 |

- 몬스터 액터 이름은 「종 - 역할」: 고블린 - 정찰병, 오크 - 주술사, 스켈레톤 - 궁수.
- 표 이름은 PDF 표 제목 기준, Foundry 그룹 접두어 유지: 몬스터 공격 - 악마, 사고 - 마법, 여정 - 2. ~에서 끝난다.
- 솔로 모험 경유지 PDF 인쇄 누락 「하는 벽」 → **응시하는 벽**(사용자 결정).

## 원문과 다르게 둔 곳

- 영문에만 있는 Foundry 안내(보물 카드, 비밀 타일 등)는 PDF 문체로 번역.
- PDF에만 있는 쪽 번호 참조는 링크 라벨로 바꾸거나 삭제.
- PDF 오기는 교정: 드뭄·비상용 → 드묾, 드레나스 → 드라나스, 살라만더 → 샐러맨더 등.
