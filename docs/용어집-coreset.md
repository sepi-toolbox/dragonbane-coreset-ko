## 무기 명명 규칙

- 서구 무기 고유명은 음역: 브로드소드, 롱소드, 숏소드, 그레이트소드, 시미터, 할버드, 랜스, 플레일, 모닝스타, 메이스, 워해머
- 일반 명사형은 의역: 손도끼, 전투도끼, 양손 도끼, 짧은 창, 긴 창, 삼지창, 지팡이, 투석구, 나무 곤봉
- `Mastercrafted X` → **명품 X**
- `Light / Heavy X` → **경량 / 중량 X** (석궁·워해머), 둔기는 **가벼운 / 무거운 둔기**

## 마법 학파별 주문 표기 원칙

- 효과가 곧 이름인 주문은 의역: 화염구, 상처 치유, 마법 방패, 순간이동
- 정령 소환 주문은 정령 이름 그대로: 노움, 샐러맨더, 실프, 운디네
- 슬래시 표기 유지: `Heat/Chill` → 가열/냉각, `Open/Close` → 열기/닫기, `Lock/Unlock` → 잠그기/열기

## 생성표(제너레이터) 표 이름

`The Journey - 1. The journey is` 처럼 문장 조각이 이어지는 표는 한국어 어순에 맞춰 조각을 옮겼습니다.
표 결과 본문을 번역할 때 이 어순을 기준으로 문장이 이어지도록 맞춰야 합니다.

| 영문 | 한국어 |
|---|---|
| The Journey / The Quest / The Adventure Site | 여정 / 임무 / 모험 장소 |
| Create NPC | NPC 만들기 |
| Mishap - Magic / Melee / Ranged / Journey | 사고 - 마법 / 근접 / 원거리 / 여정 |
| Monster Attacks - X | 몬스터 공격 - X |
